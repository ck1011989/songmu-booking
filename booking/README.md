# 鬆沐預約日期管理

編輯 availability.json，日期格式 YYYY-MM-DD，start 為開放時間，end 為結束時間（24:00 代表午夜）。bookings 填入已確認預約的開始、結束時間，例如：

```json
{"2026-10-07":{"start":"18:00","end":"24:00","bookings":[{"start":"18:00","end":"19:30"}]}}
```

頁面每 30 分鐘提供一個候選開始時間，依服務長度排除超過營業結束及與已確認預約衝突的時段，前後保留 10 分鐘整理。運動評估暫預留 30 分鐘，請依實際服務時間調整。

收到 LINE 預約並確認後，請立即在 bookings 加入該筆開始、結束時間並儲存；GitHub Pages 部署完成後才會更新。取消預約後移除該筆時段。請勿填入姓名、電話或其他客戶個資，這是公開 repository。

此版本產生可複製的 LINE 預約申請，不會自動傳送或鎖定時段；收到店家回覆確認後才成立。未串接伺服器，無法原子阻擋多人同時申請。
